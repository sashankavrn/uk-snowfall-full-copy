To support this workflow, the Lambda requires full execute-api permissions and API Gateway management permissions scoped to the account. These permissions are necessary for:

Sending messages to connected snowfall service agent (client) devices

Managing WebSocket connections

Invoking API Gateway routes

Supporting future API Gateway changes without requiring additional IAM updates
